# 《数字经济一本通关》公开简化版制作大纲

> 版本：第三版（2026-08-30）  
> 内容底稿：《数字经济一本通关》完整版  
> 核心原则：简化版不是完整版的章节摘要，而是用一套稳定框架展示教材知识之间的关系，并通过具体题目证明这套框架能够解释现实问题。

---

## 一、产品定位

公开简化版只完成三件事：

1. 让读者意识到，数字经济热点不断变化，仅靠追逐新名词很难形成稳定认识；
2. 建立一套以教材内容为基础的五层分析框架，把分散知识组织成完整结构；
3. 通过一道真题和一道前沿问题，展示框架如何连接教材知识、解释问题并形成判断。

因此，简化版不是“15章压缩版”，也不是目录、知识点清单或第15章扩写。它的整体推进关系是：

> **问题意识 → 五层框架 → 真题应用 → 新题迁移 → 获取完整版**

它需要推动读者完成三次心理转换：

> **“数字经济内容很散。”**  
> → **“原来这些内容可以这样组织。”**  
> → **“这套框架确实能解释题目和现实。”**  
> → **“我希望获得完整的知识与训练体系。”**

# 01｜为什么数字经济需要一套稳定框架

## 1. 本部分的核心判断

平台、数据、数字金融、人工智能、算法治理等问题仍在快速变化，热点会更新，院校侧重点和命题材料也会变化。但是，考试和现实分析不能只靠追逐热点完成。

真正需要建立的是：

> **用稳定的底层框架，处理不断变化的新问题。**

## 2. 内容边界

这一部分只负责建立问题意识，不展开具体知识点，也不提前介绍五层框架的细节。文字应短，最多完成以下三步：

1. 数字经济研究对象持续变化；
2. 新问题仍然需要稳定的经济学解释；
3. 教材知识可以被重新组织为一套共同框架。

结尾直接进入第二部分：

> **下面先不进入任何一个具体知识点，我们先把整门数字经济放进一套共同的分析框架。**

# 02｜数字经济的五层分析框架

这是简化版的核心，但展示方式应当简洁。参考教材《教学大纲》的框架写法，本部分只用一张总框架和少量说明，建立五个层次之间的关系，不在大纲中继续展开各章知识。

## 1. 框架展示

```
第一层  对象与边界（第1章）       传统经济对照 → 内涵与边界 → 特征与测度
第二层  核心经济机制（第3—5章）   网络外部性 → 双边市场 → 价格结构
第三层  市场结构与数据（第6—7章） 平台行为 → 市场集中 → 数据要素与数据壁垒
第四层  经济与社会后果（第8—12章）
        ├─ 效率、发展与创新       增长 → 就业创造 → 金融与产业发展
        └─ 权力、分配与风险       市场力量 → 收入分化 → 数据、金融与算法风险
第五层  治理与制度平衡（第6、12章）
                                  反垄断 → 数据、隐私与算法治理 → 发展与规范平衡

贯穿工具  理论工具（第2章）｜证据工具（第13章）
前沿入口  AI、大模型与Web3（第14章）
```

五层表达的是分析层次，不是所有数字经济现象都必须经历的统一产业演化过程。第2章负责解释“为什么”，第13章负责检验“是否成立”，第14章的新问题重新进入前面的五层框架。

## 2. 第一层的配图提示

第一层用“传统经济”建立参照，可配一张横向教材型插图：

> **传统经济 → 数字技术与数据 → 数字经济**

左侧呈现实体商业、传统制造、银行网点和线下治理；中间呈现互联网、平台、算法和数据进入经济活动；右侧呈现线上线下融合、智能制造、数字金融和数字化治理。画面同时表现数字产业化和产业数字化，不使用机器人、巨型AI大脑或泛化的未来城市。

## 3. 写作边界

- 总图只保留每层最有代表性的知识点，不塞入15章目录；
- 每一层用一至两个关键关系说明其作用，不写成章节内容介绍；
- 本部分只介绍框架，不讲如何答题；完整调用留到第三部分；
- 详细内容以 [`five-layer-framework.md`](five-layer-framework.md) 为底稿进一步压缩。

结尾直接过渡：

> **下面选取一道真实题目，观察这五个层次怎样在同一个问题中连接起来。**

# 03｜用五层框架分析一道真题

这是公开简化版的第一次完整应用，也是说服力最强的一部分。

## 1. 真题选择原则

具体题目尚未确定，写作前必须先找到并核验真实来源，记录院校、年份、考试科目和原题表述，不得把自拟题包装成真题。

优先选择“平台垄断的形成原因及治理”一类综合题，因为它能够自然调用五层内容：

- 对象与边界：平台、垄断、市场集中和滥用行为分别是什么；
- 核心经济机制：网络外部性、双边市场与价格结构；
- 市场结构与数据：规模经济、数据反馈、进入壁垒和平台行为；
- 经济与社会后果：匹配效率与创新收益，以及市场力量、分配和风险；
- 治理与制度平衡：反垄断、数据和算法治理及效率抗辩。

若最终真题不能自然覆盖上述关系，应更换题目，而不是为了展示框架强行套满五层。

## 2. 建议写作结构

### 2.1 先呈现原题与直觉回答

先给出核验后的真题原文，再展示一个常见但解释力不足的回答，例如“平台依靠规模优势形成垄断，应当加强监管”。这里的作用是立起问题：结论可能没有错，但尚未解释规模优势从哪里来、集中何时构成损害、治理应当针对什么机制。

### 2.2 用一张小图完成框架定位

只高亮本题实际涉及的层次和知识点，不重复第二部分的完整总图。读者需要一眼看到本题的主线，而不是再次阅读一张知识目录。

### 2.3 按因果关系展开分析

建议形成如下核心链条：

> **网络外部性与需求侧规模形成**  
> → **平台通过双边价格结构扩大和协调用户规模**  
> → **规模经济、数据反馈与转换成本形成集中及进入壁垒**  
> → **效率创新收益与市场权力风险并存**  
> → **治理针对具体行为，并保留效率抗辩和创新空间**

正文必须真正调用教材模型或关键条件，不能把网络效应、双边市场、数据壁垒等名词并列堆放。

### 2.4 区分三个容易混淆的概念

- 市场集中不等于企业违法；
- 市场支配地位本身不违法；
- 利用支配地位实施排除、限制竞争的滥用行为才进入违法判断。

### 2.5 形成完整回答

结尾把前面的分析压缩成一份可直接阅读的完整论述，使读者看到“普通答案”和“系统答案”的差别。必要时补充证据问题：怎样用市场份额、HHI、勒纳指数、进入壁垒或因果识别检验相关判断。

## 三、统一制作原则

### 1. 必须紧扣教材

- 所有定义、机制、模型、案例口径和治理结论均以完整版教材为知识底稿；
- 每个重要知识点在写作时标注教材章节来源，排版后可以弱化章号，但不能失去知识依据；
- 不把教材没有建立的概念或因果关系写入框架；
- 特别注意区分网络外部性、零边际成本、规模经济和数据非竞争性，避免把不同机制混成一条未经教材论证的因果链。

### 2. 框架优先于目录

- 第二部分介绍五层结构，不按15章顺序复述教材；
- 章节编号用于校验知识来源，不作为正文的主要组织方式；
- 每一层都应说明该层知识之间的内部关系，而不是罗列名词。

### 3. 图文分工明确

- 总图负责展示层次与关系，正文负责解释概念与机制；
- AI插图负责建立直观比较或现实场景，不承担大量精确文字和复杂模型；
- 需要精确标签、公式或因果关系时，使用可控的信息图、表格或排版图，而不是完全交给AI生成；
- 所有图片都必须服务于框架理解，避免只提供泛科技氛围。

### 4. 真题必须核验

- 真题必须具有可追溯来源；
- 保留院校、年份、科目和原始表述；
- 找不到可靠出处时明确标注为“模拟题”或“现实问题”，不得混称真题。

### 5. 写作语气

- 先解释“为什么”，再给结论；
- 少用口号和抽象判断，多展示知识之间的关系；
- 不堆砌名词，不追求把所有内容塞入一道题；
- 只保留一道完整真题和一道简短前沿题，不继续增加题目数量或单独扩写方法总结；
- 简化版的目标是让读者感到框架清楚、解释有力，并自然产生继续阅读完整版的需要。
