# 《数字经济一本通关》教材框架

> 本文独立保存教材从第1章到第15章“先讲什么、后讲什么、为什么这样衔接”的纵向讲授框架。它与公开简化版采用的五层分析框架使用同一批教材知识，但组织目的不同：教材框架还原章序与教学逻辑，五层框架负责跨章节组织问题。

---

## 一、教材的总体结构

当前《数字经济一本通关》共15章。教材不是把数字经济知识按行业或政策条目平铺罗列，而是按“建立对象—解释机制—分析后果—进入场景—治理与验证—综合装配”的顺序展开。

```mermaid
flowchart LR
    A[对象与工具<br/>第1—2章<br/>研究什么、怎样分析] --> B[微观机制<br/>第3—6章<br/>规模形成、平台组织、价值变现、竞争集中]
    B --> C[数据与宏观<br/>第7—9章<br/>数据成为要素及其增长、就业与分配后果]
    C --> D[金融与产业场景<br/>第10—11章<br/>机制在金融、企业、产业和贸易中的落地]
    D --> E[治理、证据与前沿<br/>第12—14章<br/>如何约束、如何检验、如何分析新技术]
    E --> F[综合装配<br/>第15章<br/>按数字企业生命周期串联全书]
```

## 二、各板块是怎样展开的

### 第一板块：先界定对象，再准备分析工具（第1—2章）

第1章先回答“数字经济是什么”：从定义和统计口径出发，说明数字产业化、产业数字化和“四化”框架，再用零边际成本、边际收益递增与三大定律概括它区别于传统经济的特征，最后处理概念边界和规模测度。因此，第1章并非单纯的概念章，而是在为后文规定研究对象、基本假设和统计口径。

第2章紧接着回答“数字经济怎样分析”：最优化处理单个主体的选择，博弈论处理平台、企业和用户之间的策略互动，信息经济学处理逆向选择、道德风险、信号和拍卖，概率统计处理不确定性。它在章序上位于前面，在实际使用中却贯穿全书，例如第3—6章的平台模型、第7章的数据拍卖、第10章的数据征信都会回到这些工具。

这一板块的衔接关系是：**先说明研究什么，再说明用什么语言和工具研究。**

### 第二板块：从规模形成推到市场结构（第3—6章）

这是教材最连续、最核心的一条理论链：

1. **第3章解释规模为何自我强化**：网络外部性使产品价值随用户规模变化，由此产生临界规模、多重均衡、预期协调、路径依赖、锁定、兼容性和赢家通吃。
2. **第4章解释规模如何被平台组织**：当不同用户群体之间存在交叉网络外部性时，平台通过价格结构同时协调两侧，解决鸡生蛋问题，并围绕单归属、多归属、竞争瓶颈、排他和包抄展开竞争。
3. **第5章解释平台如何把规模转化为收入**：价格歧视、个性化定价、免费与Freemium、注意力经济、广告竞价、佣金与抽成，都是第4章“价格结构”在商业层面的具体实现。
4. **第6章解释规模与变现为何可能转化为市场力量**：网络效应、规模经济和数据反馈叠加后形成集中，继而出现自我优待、杀手型并购、“二选一”和算法合谋，最后进入市场界定、势力测度与反垄断制度。

因此，这四章不是四个并列专题，而是一条“**规模形成 → 平台组织 → 商业变现 → 竞争集中与规制**”的因果链。

### 第三板块：从关键要素推到总量与分配（第7—9章）

第7章把前面多次出现的数据单独抽出，依次回答“数据是什么、归谁、值多少、怎样交易、如何入表”。这里完成的是从企业经营资源到独立生产要素和资产的概念升级。

第8章将数据和数字基础设施放入增长核算、索洛模型与内生增长框架，讨论数字化是否提高生产率、为什么会出现索洛悖论，以及长期增长与收敛条件。分析层级由企业和市场上升到宏观总量。

第9章继续追问增长收益如何分配：技术对任务和岗位既有替代也有创造，进而影响就业极化、技能溢价、零工用工、劳动收入份额、数据租金和数字鸿沟。它使第8章的“增长多少”进一步转向“谁受益、谁承担调整成本”。

这一板块的逻辑是：**数据作为要素 → 产出与生产率后果 → 就业与收入分配后果**，即从要素投入推进到总量结果，再推进到结构和公平问题。

### 第四板块：进入金融与产业两个现实场景（第10—11章）

第10章选择金融场景，先从金融中介功能出发，再讨论互联网金融、数字普惠金融、大数据风控与征信，最后进入区块链、稳定币、数字人民币和货币政策传导。教材的判断不是“技术消灭金融中介”，而是技术改变中介功能的实现方式，同时产生期限错配、挤兑、隐私和监管等新风险。

第11章选择实体产业与跨境交换场景，从数字产业自身的形成出发，转向数字技术如何改变企业边界、成本结构和投资决策，再用长尾与范围经济解释产品和渠道扩张，继而延伸到数字贸易、跨境数据流动与产业政策。

两章合起来回答：前面建立的网络、平台、数据和增长机制，进入金融体系、企业生产与国际交换后，具体改变了什么。

### 第五板块：从规范治理到证据检验，再迁移到前沿（第12—14章）

第12章先处理规范问题：从隐私的成本收益权衡出发，进入数据治理法律体系、知情同意、数据出境与算法治理，再讨论平台责任和数字税。其基本写法是先说明市场失灵或利益冲突，再比较制度工具，而不是先给出监管口号。

第13章处理证据问题：OLS建立基准回归并揭示内生性约束，DID、IV、RDD、匹配和合成控制进一步处理因果识别，再通过生产率、宽带政策、指数构造和平台A/B实验把方法落回数字经济问题。它与第2章共同构成全书的两类方法基础：第2章负责理论推理，第13章负责经验检验。

第14章处理新问题：AI的就业影响复用第9章任务模型，算法合谋复用第6章竞争分析，大模型生态复用第3—4章的规模经济和平台理论，Web3代币机制复用第2章委托代理与第10章货币理论。它要训练的不是记忆新名词，而是“识别经济结构—调用已有工具—形成证据与政策判断”的迁移能力。

### 第六板块：用企业生命周期回收全书（第15章）

第15章把前14章从“学科章节”重新装配成“企业决策链”：

- **冷启动**：鸡生蛋问题、预期自我实现与补贴买预期；
- **增长**：网络效应、零边际成本和数据飞轮；
- **经营**：两侧价格结构、规模变现与用户价值、数据利用与隐私保护；
- **竞争**：围绕用户归属和数据获取展开排他、并购、自我优待与算法竞争；
- **垄断与治理**：反垄断、数据与算法治理、税收及宏观分配后果；
- **新一轮冷启动**：AI、大模型与Web3改变技术和成本条件，新的企业与平台再次进入前述循环。

生命周期不是严格的企业编年史：冷启动和增长主要按时间划分，经营、竞争和垄断主要按市场结构划分，彼此可能重叠。它的作用是帮助读者判断一个现实问题处在什么阶段，进而回到前14章调用相应工具。

## 三、教材反复使用的展开方法

从各章正文看，教材讲解一个主题时通常沿以下层次推进，但不会要求每一章机械套用同一模板：

1. **概念与边界**：先回答对象是什么、与相近概念怎样区分。
2. **机制与模型**：再说明为什么会发生，用效用、利润、均衡、增长或因果模型把逻辑写清。
3. **行为、结构与福利后果**：分析主体会怎样选择，市场结构如何变化，效率收益与分配代价分别是什么。
4. **制度、案例与证据**：最后进入现实案例、政策工具、适用条件及经验检验。

例如，第3章按“概念—模型—兼容与锁定—市场结构”展开；第7章按“属性—产权—定价交易—资产入表”展开；第11章按“数字产业—传统产业转型—需求结构—国际贸易—产业政策”展开；第12章按“隐私经济学—法律制度—平台责任—国际税收”展开。共同点都是从原理走向应用和制度，而不是从政策结论倒推理由。

## 四、教材的几条纵向主线

如果不按章号记忆，全书可以压缩为四条彼此交叉的纵向线索：

- **市场机制线**：网络外部性 → 双边市场 → 定价变现 → 竞争与垄断（第3—6章）。
- **数据影响线**：数据要素 → 增长与生产率 → 就业与分配 → 金融、产业与贸易 → 数据治理（第7—12章）。
- **方法证据线**：理论推理工具（第2章）＋计量与因果识别（第13章），分别回答“为什么”和“现实中是否成立”。
- **迁移综合线**：前沿技术复用旧工具（第14章）＋企业生命周期重新装配全书（第15章）。

一句话概括教材章序：

> **界定对象，准备工具；从网络效应讲到平台、定价与竞争；再从数据要素讲到增长、分配及金融产业应用；最后进入治理、证据和前沿，并用企业生命周期完成综合。**
