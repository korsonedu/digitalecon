# 第二讲 网络外部性基本模型：u = θn − p

> 原型：数学推导节｜对应书节：3.2.1｜目标时长 10 分钟

## 开场定题（约 0:40）

这一讲讲网络外部性的基本模型：u = θn − p。它回答三个问题：网络产品的需求函数如何从效用推导出来，均衡如何由预期确定，为什么网络产品的命运两极分化。传统商品的价值由其自身属性决定，网络产品的价值取决于有多少人在用，这一差别改变了需求曲线的形状与均衡的个数。本节把网络外部性写成效用函数，逐层推出需求函数、反需求函数与临界规模，第 3 讲的预期协调模型直接建立在本讲的多重均衡结构上。

## 主体（约 7:20）

### 1. 模型设定

网络外部性（network externality）指某一产品的价值随使用该产品的用户数量的增加而增加，此时每个用户的加入都直接提高了存量用户的效用。电话网络、操作系统、社交平台皆属此类：使用微信的人越多，微信对每个人的价值越高。与传统商品不同，网络产品的效用函数必须把用户规模直接写进去，这正是本模型的做法。按传导路径，网络外部性分为直接与间接两类：直接网络外部性经用户之间的直接互动传导，间接网络外部性经互补品市场传导；本节的效用函数把用户规模直接写进效用，刻画的是直接网络外部性。

考虑一个单一网络产品。消费者对网络价值的偏好强度记为 θ（西塔），它刻画消费者的异质性：θ 高的消费者更看重网络规模。θ 在 [0, 1] 上均匀分布。网络规模记为 n，标准化为用户比例，取值在 [0, 1] 之间；接入价格记为 p。类型为 θ 的消费者在网络规模为 n 时接入的效用为

【屏显】u(θ) = θn − p

效用由两项构成：θn 是网络价值，等于偏好强度乘网络规模；减去 p 是接入价格。θ 高的消费者从同样的网络规模中获得更多效用。网络规模为零时，网络价值项为零，接入的效用为负，无人愿意接入，网络产品由此天然带有启动难题。

网络产品的需求与传统商品还有一个根本差别：传统商品的需求由价格单独决定，网络产品的需求由价格与预期共同决定，预期一动，整条需求曲线随之移动。对网络价值的刻画，本模型取线性形式 θn，这是梅特卡夫定律（Metcalfe's law）的保守版本。梅特卡夫定律认为网络的价值与用户数的平方成正比：n 个用户两两之间有 n(n−1)/2 条连接，每条连接都有价值。若把网络价值写成平方形式，后文的正反馈只会更强，结论方向不变。

### 2. 需求函数：预期决定接入

接入决策面对一个时间上的困难：消费者决定是否接入时，网络规模尚未实现，只能依据对它的预期。预期网络规模记为 nᵉ（n 带 e 上标）。给定预期 nᵉ，类型为 θ 的消费者接入后的净效用为 θnᵉ − p。推导需求的标准手法是找边际消费者：θ 在 [0, 1] 上连续取值，逐个类型分析不可行，但只要找到接入与不接入之间的临界类型，它两侧的消费者自动分成两群，接入比例立即可算。接入与不接入之间的边际消费者，其效用恰好为零，满足

【屏显】θnᵉ − p = 0

解出边际消费者的类型为 θ̂ = p/nᵉ。θ 高于 θ̂ 的消费者接入后效用为正，接入；θ 低于 θ̂ 的消费者接入后效用为负，不接入。这里用到均匀分布（uniform distribution）的基本性质：取值落在某个区间内的概率等于区间长度。θ 在 [0, 1] 上均匀分布，接入用户占全体消费者的比例就是区间 [θ̂, 1] 的长度，等于 1 减 θ̂。网络规模 n 正是接入用户的比例，因此需求为

【屏显】n = 1 − θ̂ = 1 − p/nᵉ

给定价格 p，需求是预期规模的函数。两个方向的反应都写在这个式子里：价格越高，接入的人越少；预期规模越大，接入的人越多。求导在这里的作用是判断变化方向：把价格 p 看作常数，需求 n 对预期 nᵉ 求导，导数大于零表示需求随预期同向变化。对预期规模求导：

【屏显】∂n/∂nᵉ = p/(nᵉ)² > 0

导数严格为正，需求是预期规模的增函数：预期越乐观，同一价格下的实际需求越大，这就是正反馈的数学形式。把同一关系写成反需求形式 p = nᵉ(1−n)：给定用户规模，消费者愿意支付的价格与预期规模成正比，预期上升使整条需求曲线向外移动。这正是需求方规模经济（demand-side economies of scale）的含义：供给方规模经济（supply-side economies of scale）来自成本曲线的下移，需求方规模经济来自需求曲线本身的移动，其来源在消费侧。

### 3. 预期自我实现与反需求函数

需求取决于预期，但预期不能任意设定。均衡的定义要求预期不系统性落空：如果人人预期 nᵉ，实际需求却偏离 nᵉ，说明预期被现实否定，人们会修正预期，状态还没有稳定下来。要求实际规模恰好等于预期规模，即理性预期（rational expectations）条件，n = nᵉ。把这一条件代入需求函数

【屏显】n = 1 − p/n

移项整理，得到网络外部性下的反需求函数（inverse demand function）：

【屏显】p = n(1−n)

它的读法是：给定用户规模 n，边际消费者愿意支付的最高价格是 n(1−n)。价格是用户规模的倒 U 形函数，在 n = 1/2 处达到最大值 1/4。倒 U 形来自两个相反的力量：网络规模上升提高每个用户的网络价值，支付意愿随之上升；但边际消费者的类型 θ̂ = 1 − n 随规模上升而下降，新增用户越来越不看重网络。规模小于 1/2 时前一种力量主导，价格随规模上升；超过 1/2 后后一种力量主导，价格随规模下降。1/4 由此成为网络产品的价格天花板：价格高于 1/4 时方程无解，均衡不存在，产品无法启动。

### 4. 多重均衡与临界规模

对给定价格 p 低于 1/4，方程 p = n(1−n) 有两个根。求交点就是解方程，先整理成 n 的二次方程 n² − n + p = 0。这里用到的工具是求根公式：一元二次方程 ax² + bx + c = 0 的两个根为

【屏显】ax² + bx + c = 0

【屏显】x = [−b ± √(b²−4ac)]/(2a)

本方程中 a = 1、b = −1、c = p，代入解出

【屏显】n₁* = (1 − √(1−4p))/2 < 1/2

【屏显】n₂* = (1 + √(1−4p))/2 > 1/2

同一价格对应两个均衡规模，这就是多重均衡（multiple equilibria）。两个均衡的性质不同。判定均衡是否稳定，标准做法是扰动实验：把规模从均衡位置挪开一点，看它自己走回来还是越走越远。设消费者根据当前规模调整预期，下一期的预期等于当期的实际需求，迭代式就是扰动实验的数学写法：

【屏显】n(t+1) = 1 − p/n(t)

动力学分为三个区间。当期规模低于 n 一星时，实际需求低于预期，网络收缩趋向于零；当期规模位于 n 一星与 n 二星之间时，实际需求高于预期，网络扩张并收敛于 n 二星；当期规模高于 n 二星时，预期过度乐观，需求回落至 n 二星。n 一星称为临界规模（critical mass），是不稳定均衡；n 二星是稳定均衡。临界规模的经济含义：网络必须越过 n 一星才能启动正反馈并收敛于大网络均衡；低于临界规模，网络因预期崩塌而消亡。

对求根公式再做一步比较静态，能看到价格的角色：n 一星对 p 求导

【屏显】dn₁*/dp = 1/√(1−4p) > 0

临界规模随价格上升而上升：价格越高，启动所需的初始用户越多，高价产品的启动门槛更高。这一结论解释了网络产品的冷启动（cold start）难题：新产品没有初始用户，正反馈无从启动，只能靠低价与免费先把规模堆过门槛，具体策略与案例在第 3 讲展开。

把反需求曲线画出来，均衡的结构一目了然。横轴是用户规模 n，纵轴是价格 p，曲线 p = n(1−n) 是过原点、最高点位于价格 1/4 处的倒 U 形。给定价格 p₀ 低于 1/4，水平线与曲线的两个交点中，左交点是临界规模，右交点是稳定均衡；两交点之间正反馈推动网络扩张至稳定均衡，临界规模以下网络收缩至零，稳定均衡右侧过度乐观的预期同样回落。这一图形结构解释了现实中网络产品"要么大成、要么消亡"的极端命运：网络外部性使中间状态不稳定。

## 经济学解释（约 1:00）

模型的因果链条是一个正反馈循环：用户规模扩大提升网络价值，网络价值提升吸引新用户，新用户加入进一步扩大规模。临界规模把这个循环切成两段：在临界规模以下，反向循环占据主导，用户流失降低网络价值，价值下降加速流失，网络收缩至零；越过临界规模，正向循环接管，扩张自动进行，直至稳定均衡。稳定均衡的规模只由价格决定，价格越低，稳定均衡越大。这一循环同时具有市场结构含义：需求方规模经济可能自我强化至赢家通吃（winner-take-all），正反馈不断放大规模差距，市场被单一网络占据，这是后续平台竞争与反垄断分析的线索。网络外部性使中间状态不稳定，市场不会停留在不温不火的规模上，要么越过门槛做大，要么消亡。临界规模与成本侧的盈亏平衡点（break-even point）形成对照：盈亏平衡点来自成本结构，是收入与成本打平所需的销量；临界规模来自需求结构，是启动正反馈所需的用户规模。两者都是企业活下来的门槛，一个在成本侧，一个在需求侧。

## 算例（约 0:40）

取价格 p₀ = 0.12，代入求根公式：√(1−4×0.12) = √0.52 ≈ 0.72，临界规模 n 一星 = (1−0.72)/2 = 0.14，稳定均衡 n 二星 = (1+0.72)/2 = 0.86。同一价格 0.12 对应两个均衡规模，0.14 与 0.86。

从不同的初始规模出发，走一遍调整过程。初始规模 0.10，低于临界规模：下一期需求为 1 − 0.12/0.10 = −0.2，负需求意味着无人接入，网络直接消亡。初始规模 0.30，位于两个均衡之间：下一期 1 − 0.12/0.30 = 0.60，再下一期 1 − 0.12/0.60 = 0.80，再下一期 1 − 0.12/0.80 = 0.85，逐渐逼近稳定均衡 0.86。初始规模 0.90，高于稳定均衡：下一期 1 − 0.12/0.90 ≈ 0.87，回落到 0.86 附近。三组初始值分别演示了消亡、扩张与回落三种命运，临界规模 0.14 是分水岭。

## 收尾（约 0:20）

本讲小结：效用函数 u = θn − p 是网络外部性的标准建模起点；需求 n = 1 − p/nᵉ 是预期规模的增函数，正反馈由此而来；预期自我实现给出倒 U 形反需求 p = n(1−n)，价格上限 1/4；同一价格对应临界规模与稳定均衡两个均衡，越过临界规模正反馈接管，低于临界规模网络消亡。下一讲进入 Katz–Shapiro 预期协调模型：多个均衡并存时哪一个被选中，预期在均衡选择中起什么作用。
