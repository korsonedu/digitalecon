# 第十三讲 一级价格密封拍卖：最优出价

> 原型：数学推导节｜对应书节：2.6.7｜目标时长 10 分钟

## 开场定题（约 0:40）

这一讲讲一级价格密封拍卖的最优出价。规则很简单：各投标人密封报价，最高报价者胜出，按自己的报价支付。问题是出多少：出价越高胜率越高，胜出后盈余越薄。本讲推出均衡出价函数，核心结论：最优出价低于估价，投标人越多越接近估价，均匀分布下 b(v) = (n−1)v/n。这是全季第一次求解一个完整的最优化问题，方法与结论都会在收益等价定理中复用。

## 主体（约 7:20）

### 1. 出价的权衡

一级价格密封拍卖（first-price sealed-bid auction）中，支付额与自己的出价直接挂钩：出价即价格，现实中的采购招标与产权转让多采用这一形式。出价越高，胜出概率越大，胜出后的盈余 v − b 越薄；出价越低，盈余越厚但胜出概率越小。投标人面对的胜出概率曲线随出价向右下倾斜，压低出价的逻辑与垄断者限制产量抬高价格同构：最优出价使"胜出概率"与"胜出盈余"的边际变化相抵。第 12 讲的诚实出价在这里失效：如实出价胜出时盈余恰为零，任何压低出价的余地都有利可图。

### 2. 设定与胜出概率

设 n 个投标人，各人的估价 v_i 独立同分布，分布函数为 F、密度函数为 f。概率工具随讲：分布函数 F(v) 的含义是估价不超过 v 的概率，密度函数 f 是它的导数；均匀分布的情形 F(v) = v、f(v) = 1。求对称均衡：所有投标人使用同一个出价函数 b(v)，且 b 严格递增，估价高者出价高。对称性的含义是同质投标人面对相同的环境应采取相同的行为，它的简化价值在于把 n 个投标人各自的策略问题压缩成同一个函数 b(v)，均衡求解从 n 元问题化为一元问题；严格递增保证估价最高者出价最高，拍品配置给估价最高者，配置有效。设估价为 v 的投标人出价 b。他的对手按 b(v_j) 出价，对手的出价低于 b 等价于对手的估价低于 b 的反函数值 b⁻¹(b)。这里用到的工具是反函数：给定出价 b，解出使用该出价的估价水平。独立同分布下，每个对手估价低于 b⁻¹(b) 的概率为 F(b⁻¹(b))，独立事件同时发生的概率等于各自概率的乘积，其他 n−1 人全部低于该水平的概率为 F(b⁻¹(b))ⁿ⁻¹，这也是出价 b 的胜出概率。期望收益为

【屏显】(v − b)·F(b⁻¹(b))ⁿ⁻¹

### 3. 一阶条件

对出价 b 求一阶条件，用到乘积法则与链式法则。决策变量是 b：投标人只能选择出价，估价 v 是给定的参数，最优化对 b 进行。第一项 (v−b) 的导数为 −1，乘胜出概率 Fⁿ⁻¹；第二项胜出概率对 b 求导，内层是 b⁻¹(b)，反函数的导数等于原函数导数的倒数，故其导数为 1/b′(v)，整个第二项为 (n−1)Fⁿ⁻²f·(1/b′)。两项之和为零：

【屏显】−Fⁿ⁻¹ + (v−b)(n−1)Fⁿ⁻²f·(1/b′) = 0

这个式子还包含未知函数 b 的反函数，无法直接求解。关键的一步是代入均衡条件：在均衡处，估价 v 的投标人使用的出价正是 b(v)，故 b⁻¹(b) = v。代入并整理，得到出价函数满足的微分方程

【屏显】b′(v)·F(v)ⁿ⁻¹ = (v−b)·(n−1)·F(v)ⁿ⁻²·f(v)

这里用到的工具是微分方程：含未知函数及其导数的方程，解是一个函数而非一个数。一阶条件的含义：出价提高一单位，胜出概率上升带来的边际收益 (v−b)·(n−1)Fⁿ⁻²f，恰好等于盈余变薄造成的边际损失 Fⁿ⁻¹，两者相抵。

### 4. 求解：均匀分布情形

取均匀分布 F(v) = v、f(v) = 1（估价在 [0,1] 上均匀分布），微分方程化简为

【屏显】b′(v)·vⁿ⁻¹ = (v−b)·(n−1)·vⁿ⁻²

两边同除以 vⁿ⁻²，得 vb′ + (n−1)b = (n−1)v。求解一阶线性微分方程的标准手法是凑乘积法则：把 b′ 与 b 的项合成某个乘积的导数。等号左边恰好是 vⁿ⁻¹·b(v) 对 v 求导的展开式，两边同乘以 vⁿ⁻² 后得到

【屏显】(d/dv)[vⁿ⁻¹·b(v)] = (n−1)·vⁿ⁻¹

两边对 v 积分，积分的工具是微积分基本定理：求导与积分互为逆运算。积分得 vⁿ⁻¹·b = (n−1)·vⁿ/n + C。边界条件 b(0) = 0：估价为零者出价为零，否则胜出即亏损，代入得 C = 0。解出均衡出价函数

【屏显】b(v) = (n−1)·v/n

三个读法。其一，出价低于估价：n 有限时 (n−1)/n < 1，胜出盈余 v/n 为正。其二，投标人越多，出价越接近估价：n 趋于无穷时 b(v) 趋于 v，竞争完全挤干了盈余。其三，两人时 b(v) = v/2，出价只有估价的一半。压制出价的程度与竞争强度成反比，这正是"胜出概率与胜出盈余权衡"的数量表达。还可以把 b = v 代入微分方程检验压价的必然性：左边为 Fⁿ⁻¹，右边为零，方程不成立，诚实出价在任何分布下都非均衡，压价是规则的直接推论。

最后把解代回微分方程验证：b′ = (n−1)/n，左边等于 (n−1)·vⁿ⁻¹/n，右边等于 (v − (n−1)v/n)·(n−1)·vⁿ⁻²，即 (v/n)·(n−1)·vⁿ⁻²，两边相等，解无误。

### 5. 二人情形的直接验证

均衡解可以用二人情形直接验证，工具是最优回应：给定对手策略，求自己的最优反应，两者互为最优回应即为均衡。设对手按 b(v₂) = v₂/2 出价，你出价 b 的胜出条件是对手出价低于 b，即 v₂/2 < b，等价于 v₂ < 2b；对手估价均匀分布，胜出概率为 2b。你的期望收益为 (v−b)·2b，对 b 求导得 2v − 4b = 0，最优回应 b = v/2，与均衡函数一致。互为最优回应的验证说明 b(v) = v/2 确实是二人拍卖的均衡，一般解的二人特例经得起直接检验。n 人情形同理：给定其他 n−1 人都按 b(v) = (n−1)v/n 出价，任意投标人的最优回应正是同一函数，对称均衡由此确认。这一验证方法也是第 14 讲收益等价定理的基础。

## 经济学解释（约 1:00）

因果链条：出价同时决定支付额与胜负边界，高报的收益是胜率，成本是盈余变薄。最优出价把一元出价增加的边际胜率收益与边际盈余损失配平。对称均衡里所有投标人按同一函数出价，估价最高者出价最高、配置依然有效，但每个人的出价都系统地压在自己的估价之下，压价的程度由竞争强度决定：对手越多，压价空间越小，这是投标人之间竞争性的军备竞赛在均衡中的表现。投标人在密封状态下竞价，唯一能锚定出价的是自己的估价与对手数量：估价决定出价的上限，对手数量决定压价的幅度。对称均衡的概念由此展示了它的价值：猜出所有人如何出价，只需求解一个微分方程。均匀分布是示范情形，一般分布下均衡出价没有显式解，但低于估价、随竞争增强而抬升的性质保持。这一结论直接连接收益等价定理：一级价格拍卖的压价恰好在期望意义上抵消了支付规则的差异，下一讲展开。

## 算例（约 0:40）

三人拍卖，估价范围 [0,100]，你的估价 v = 80。代入 b(v) = (n−1)v/n：b(80) = (2/3)×80 ≈ 53.3。用期望收益验算最优性：你出价 b 时，对手出价低于 b 等价于对手估价低于 3b/2，两个对手都低于该水平的概率为 (3b/200)²。出价 53.3：胜出概率 (80/100)² = 0.64，盈余 26.7，期望收益约 17.1。出价 60：胜出概率 (90/100)² = 0.81，盈余 20，期望收益 16.2，低于 17.1。出价 50：胜出概率 (75/100)² = 0.5625，盈余 30，期望收益约 16.9，同样更低。出价 55：胜出概率 (82.5/100)² ≈ 0.68，盈余 25，期望收益约 17.0，仍然低于 17.1。如实出价 80：必胜，但盈余为零，期望收益为零。53.3 处胜出概率与盈余的边际权衡恰好配平。两人情形同样可以验算：b(80) = 40，对手按 v₂/2 出价，出价 40 的胜出条件是 v₂ < 80，胜出概率 0.8，盈余 40，期望收益 32；出价 45 的胜出条件是 v₂ < 90，概率 0.9，盈余 35，期望收益 31.5；出价 35 的胜出条件是 v₂ < 70，概率 0.7，盈余 45，期望收益同样 31.5，两侧偏离都低于 32，40 确为最优。对比第 12 讲的维克瑞拍卖：同一组估价 80、50、30 下，维克瑞胜者支付 50，一级价格胜者支付约 53.3，两种机制的支付规则不同，支付额也不同，这一差异在下一讲的收益等价定理中会有一个出人意料的结论。再换人数：两人拍卖 b(80) = 40，十人拍卖 b(80) = 72，投标人越多出价越逼近估价 80，竞争强度与压价幅度的反向关系一目了然。

## 收尾（约 0:20）

本讲小结：一级价格拍卖的支付额与出价挂钩，最优出价压低在估价之下；对称均衡的一阶条件给出微分方程 b′Fⁿ⁻¹ = (v−b)(n−1)Fⁿ⁻²f；均匀分布下 b(v) = (n−1)v/n，投标人越多出价越接近估价。下一讲进入收益等价定理：四种拍卖形式给卖方带来的期望收益相同，一级价格的压价与维克瑞的次高价支付在期望上恰好扯平。
