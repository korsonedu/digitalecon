# 第五讲 Rochet–Tirole 模型：价格结构的决定

> 原型：数学推导节｜对应书节：4.2.1-4.2.2｜目标时长 10 分钟

## 开场定题（约 0:40）

这一讲进入全季的数学核心：Rochet–Tirole 模型，回答平台定价最根本的两个问题：总价格水平由什么决定，价格在两侧之间如何分配。第 4 讲的门槛条件说明了平台为什么要补贴一侧，本讲给出完整的定价模型，把"补贴给哪一侧、补到什么程度"写成公式。结论一句话：总价格水平由两侧弹性之和决定，价格结构按两侧弹性占比分摊，弹性大的一侧承担总价格中更大的份额。

## 主体（约 7:20）

### 1. 模型设定

设平台连接买方与卖方，对每笔交易向买方收取 p_B、向卖方收取 p_S，平台提供每笔交易的边际成本为 c。两侧的交易参与率分别为 D_B(p_B) 与 D_S(p_S)，价格上升时该侧参与比例下降。交易需要买卖双方同时参与，交易量与两侧参与率的乘积成正比，写成

【屏显】V = D_B(p_B)·D_S(p_S)

乘积形式的含义：两侧参与率都在 0 到 1 之间，乘积刻画"双方都在场"的比例；任何一侧参与率为零，交易量就为零。平台的利润等于每笔交易的利润乘交易量

【屏显】π = (p_B + p_S − c)·D_B(p_B)·D_S(p_S)

### 2. 一阶条件

对 p_B 求一阶条件，用到乘积法则。p_B 上升一元有两个效果：其一，每笔交易多收一元，收入增加当前交易量 D_BD_S；其二，买方参与率按 D_B′ 的速率下降，每减少一笔交易损失边际利润 p_B+p_S−c，损失额为 (p_B+p_S−c)·D_B′·D_S。利润最大化要求两个效果恰好相抵：若涨价的净效果为正就继续涨，为负就降价，最优处净效果恰为零。一阶条件为

【屏显】∂π/∂p_B = D_BD_S + (p_B+p_S−c)·D_B′D_S = 0

两边同除以 D_BD_S 并移项，得 p_B+p_S−c = −D_B/D_B′。对 p_S 求导完全对称，得 p_B+p_S−c = −D_S/D_S′。

### 3. 弹性化与价格结构条件

把一阶条件改写成弹性形式，价格由什么决定才能看清。需求弹性带一下定义：记

【屏显】η_i = −D_i′·p_i/D_i > 0

含义是价格上升 1% 时该侧参与率下降的百分比，弹性 2 的含义是涨价百分之一、参与率掉百分之二。由弹性定义，−D_i/D_i′ = p_i/η_i，两个一阶条件化为

【屏显】p_B+p_S−c = p_B/η_B

【屏显】p_B+p_S−c = p_S/η_S

两式相等即得利润最大化的价格结构条件

【屏显】p_B/η_B = p_S/η_S

这个条件的直观含义：总价格水平给定时，把 1 元价格从一侧挪到另一侧，两侧参与率的百分比变动分别为 η_B/p_B 与 η_S/p_S；两者相等意味着任何再分摊都不改变交易量，平台处于"再调整价格结构已无利可图"的临界点。

### 4. 总价格水平

结构条件给出分摊比例，总水平还需要第二个方程。这里用到的工具是合比性质：a/b = c/d 时，有 (a+c)/(b+d) = a/b。对结构条件使用合比性质

【屏显】p_B/η_B = p_S/η_S = (p_B+p_S)/(η_B+η_S)

记总价格水平 M = p_B+p_S，代入一阶条件，得到

【屏显】M − c = M/(η_B+η_S)

移项整理为加成形式，解出

【屏显】M = [(η_B+η_S)/(η_B+η_S−1)]·c

其中要求 η_B+η_S > 1：两侧弹性之和大于 1 时内点解存在，与单边垄断要求 η > 1 同构。总价格水平的读法：价格加成由两侧弹性之和决定，两侧需求对价格越不敏感，平台能加成的幅度越大。这与单边市场勒纳公式（Lerner formula）p = c·η/(η−1) 结构一致：单边垄断的加成由单一市场的弹性决定，双边平台的加成由两侧弹性之和决定。再按弹性占比分摊总水平，得到各侧价格的封闭解

【屏显】p_i = [η_i/(η_B+η_S)]·M = [η_i/(η_B+η_S−1)]·c

直接读法：弹性较大的一侧承担总价格中更大的份额。注意结论的方向：本模型中两侧需求只由本侧价格决定，弹性大的一侧被收取更高价格；"弹性大的一侧获得补贴"的经验印象，其模型基础是交叉外部性显式进入效用的建模方式，这一区别在第 6 讲展开。

### 5. 便利收益变体

基准模型假定两侧从交易中获得的收益已完全反映在各自的需求函数中。银行卡网络一类市场需要一个直接推广：商户接受银行卡本身能带来销量提升与现金管理成本的节省，这部分收益并不经由平台收费体现。设卖方每笔交易额外获得便利收益（convenience benefit）b，则卖方的净支付为 p_S − b。以 p̃_S = p_S − b 记卖方净价格，平台利润为

【屏显】π = (p_B + p̃_S + b − c)·D_B(p_B)·D_S(p̃_S) = (p_B + p̃_S − (c−b))·D_B(p_B)·D_S(p̃_S)

与基准模型形式完全一致，只是边际成本 c 被净成本 c − b 取代，全部结论原样成立，处处以 c−b 替换 c。把买方侧一阶条件整理成 p_B 的显式表达

【屏显】p_B = [η_B/(η_B−1)]·(c − b − p_S)

这一表达给出买方侧补贴的判定条件：η_B > 1 时系数为正，当 p_S > c−b 时 p_B < 0，即卖方侧承担的费用一旦超过净成本，平台就应当对买方侧发放净补贴；便利收益 b 越大，卖方越愿意承担费用，买方侧获得补贴的空间也越大。银行卡网络是这一变体的标准应用：商户接受银行卡的便利收益可观，净成本很低甚至为负，持卡人侧因此获得负价格，中国的刷卡手续费结构全部由商户承担、持卡人免费还常获积分返现，国际卡组织的交换费（interchange fee）制度同理。交换费水平因此成为各国监管的焦点：费率过高抬高商户成本并转嫁消费者，过低削弱补贴持卡人的能力、抑制用卡规模。

### 6. 三种定价目标的比较

作为扩展对照，把利润最大化与社会目标放在一起比较。平台定价目标不限于利润最大化。消费者剩余（consumer surplus）度量消费者从交易中获得的总收益，即支付意愿减实付价格的累积，几何上是反需求曲线与价格线之间的面积。交易量最大化的平台最大化 V，会持续降价直至两侧参与饱和，定价不高于零，低于利润最大化定价。社会最优最大化两侧用户剩余加平台利润，结论是总价格水平低于边际成本，即对交易给予净补贴，这与单边市场"价格等于边际成本"的教科书结论明显不同，根源在于交易需要两侧同时在场，一侧参与不足会使另一侧的接入价值落空，补贴用来压缩这部分落空的损失。三种目标的价格排序为

【屏显】p 利润最大化 > p 社会最优 > p 交易量最大化

以对称线性参与函数 D_i = 1−p_i 为例验算：利润最大化价格为 (1+c)/3，社会最优价格为 c/3，交易量最大化价格为 0，排序成立。政策含义：竞争性平台被市场压力推向交易量最大化方向，其定价低于垄断平台的利润最大化定价，平台竞争本身就在保护消费者；垄断平台相对社会最优过度收费，构成监管干预的福利基础。

## 经济学解释（约 1:00）

三个层次的结论。其一，定价决策的本质是选择结构：两个平台的总收费水平相同，利润与交易量却可以截然不同，差别全在两侧价格的分配上，淘宝击败易趣时发生的事正是如此。其二，补贴是定价的自然结果：基准封闭解中两侧价格均为正，低于边际成本甚至为负的价格来自便利收益变体与交叉外部性进入效用的建模框架，平台在低价侧的每一分亏损都是对另一侧规模的投入。其三，免费模式的根源在价格结构倾斜：数字平台普遍采取一侧免费、另一侧收费的结构，免费侧凭借其对另一侧的外部性贡献充当撬动另一侧的杠杆。把这三个结论串起来，本模型的价格结构规则回答了第 4 讲留下的问题：补贴给哪一侧，由该侧在需求中的位置决定；补到什么程度，由结构条件与净成本之间的差额决定。

## 算例（约 0:40）

取两侧弹性 η_B = 2、η_S = 4，边际成本 c = 1。总价格水平 M = (2+4)/(2+4−1)×1 = 6/5 = 1.2。按弹性占比分摊：p_B = (2/6)×1.2 = 0.4，p_S = (4/6)×1.2 = 0.8。验算结构条件：p_B/η_B = 0.4/2 = 0.2，p_S/η_S = 0.8/4 = 0.2，两侧价格弹性比相等。卖家侧弹性更大，承担总价格中更大的份额：0.8 对 0.4。

再代入便利收益变体：设 b = 0.9，卖家侧价格仍为 0.8，则 p_B = [2/(2−1)]×(1−0.9−0.8) = 2×(−0.7) = −1.4。卖方侧承担的费用超过净成本，买方侧价格转负，平台对买家每笔交易净补贴 1.4 元。两个数字并列，恰好展示了本讲两个结论：基准模型里弹性大的一侧多付钱，便利收益进入后，被补贴的空间由净成本与卖方费用的差额打开。

## 收尾（约 0:20）

本讲小结：交易量等于两侧参与率的乘积；一阶条件给出价格结构条件 p_B/η_B = p_S/η_S；合比性质加总弹性，得到总价格水平 M = (η_B+η_S)/(η_B+η_S−1)·c；各侧价格按弹性占比分摊，弹性大的一侧承担更大份额；便利收益变体以 c−b 替换 c，给出买方侧补贴的判定条件。下一讲进入倾斜式定价的比较静态：谁多付钱、谁获补贴，由什么因素决定，为什么经验上被补贴的一侧通常弹性更大。
