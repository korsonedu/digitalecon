# 第四讲 鸡生蛋问题：零均衡与临界规模推导

> 原型：数学推导节｜对应书节：4.1.3｜目标时长 10 分钟

## 开场定题（约 0:40）

这一讲讲鸡生蛋问题：双边市场的启动困境及其形式化。买家不来因为商家少，商家不来因为买家少，两侧都不愿率先进入，市场可能永远停在零规模。本节把这一困境写成模型，回答三个问题：零规模为什么是自我实现的均衡，需要多大的初始规模才能脱离零均衡，负价格如何把启动门槛完全消除。这是平台补贴一侧的商业逻辑的数学基础，第 5 讲完整的定价模型直接建立在这一节的门槛条件上。

## 主体（约 7:20）

### 1. 交叉网络外部性与鸡生蛋问题

第 2 讲的网络外部性发生在同一侧用户之间：微信用户越多，每个微信用户的价值越高。双边市场的驱动力量是它的跨侧形式：交叉网络外部性（cross-side network externality），指平台一侧用户规模的变化直接改变另一侧用户的效用，两侧用户的效用函数中相互包含对方的规模。买家越多，商家入驻的价值越高；商家越多，买家逛平台的价值越高，两侧互为对方的产品价值来源。这一相互依赖产生了平台启动的经典难题，即鸡生蛋问题（chicken-and-egg problem）：双边市场启动阶段的互为因果困境，买家不来因为商家少，商家不来因为买家少，市场无法从零规模自发启动。

### 2. 设定与参与条件

把两侧的参与决策写成依赖对方规模的条件。设商家入驻的价值为 v_S(n_B)，买家接入的价值为 v_B(n_S)，二者均为递增函数，且 v_S(0) = v_B(0) = 0：没有另一侧用户时，平台对任何人都没有价值。两侧的价格记为 p_S 与 p_B。参与条件分别为

【屏显】v_S(n_Bᵉ) − p_S ≥ 0

【屏显】v_B(n_Sᵉ) − p_B ≥ 0

上标 e 表示预期：用户根据对另一侧规模的预期做决策，均衡要求预期自我实现（第 3 讲）。这个设定的要点在于价值函数只依赖对方规模：本侧用户再多，只要对面没人，本侧价值仍然为零，这正是鸡生蛋问题的数学形态。

### 3. 零均衡的自我实现

第一步，检验零规模能否自我维持。启动阶段预期 n_Bᵉ = n_Sᵉ = 0，由 v_S(0) = v_B(0) = 0，两侧的参与条件在价格为正时均不成立：价值为零，减去价格后为负。于是两侧都不参与，实际规模 n_B = n_S = 0 恰与预期吻合。零规模是一个自我实现的均衡，市场无法从零规模自发启动。这一步是整个模型的关键：零规模是一个货真价实的均衡，预期与实际在零规模上互相锁死，任何一侧单独进入都会因另一侧缺位而亏损离场。对照传统市场：传统市场的零交易只是供给暂时缺席，价格信号会把资源引向供给恢复；双边市场的零规模是一个稳定的均衡，没有任何价格信号把市场从零规模拉出来，这是两类市场失灵的本质差别。

### 4. 临界规模门槛

第二步，求正规模均衡所需的条件。这里用到的工具是反函数（inverse function）：反函数把问题反过来问，给定目标价值 p_S，求出需要多大规模的买家才能让商家入驻。v_S 递增保证了反函数存在。参与条件 v_S(n_Bᵉ) ≥ p_S 等价于 n_Bᵉ ≥ v_S⁻¹(p_S)，买方一侧同理。记

【屏显】n̄_B = v_S⁻¹(p_S)

【屏显】n̄_S = v_B⁻¹(p_B)

n̄_B 是使卖方愿意入驻的最小买方规模，n̄_S 是使买方愿意接入的最小卖方规模。任何正规模均衡必须同时满足 n_B* ≥ n̄_B 与 n_S* ≥ n̄_S。这一对不等式界定了双边市场的临界规模：两侧规模必须同时越过各自的门槛，任一侧跌破门槛都会使另一侧退出，系统退回零均衡。双边市场的启动因此比单边更苛刻：单边只需一个规模越过门槛，双边需要两个规模同时过关，缺一不可。

### 5. 价格如何进入门槛

第三步，考察价格如何进入门槛。v_S⁻¹ 与 v_B⁻¹ 同为递增函数，故

【屏显】∂n̄_B/∂p_S > 0

【屏显】∂n̄_S/∂p_B > 0

提价抬高对方一侧的门槛，降价压低门槛。这里的逻辑值得细看：平台向卖家收多少钱，改变的是买家的门槛。对卖家收费越高，愿意入驻的卖家越少，要说服剩余卖家入驻就需要越多的买家在场，买家侧的门槛随之抬高。比较静态的读法：∂n̄_B/∂p_S > 0 说的是，平台对卖家的收费每高一点，说服商家入驻所需的买家规模就大一点，买方侧的门槛与卖家侧的价格同步抬高。特别地，当 p_S ≤ 0 时，由 v_S(0) = 0 ≥ p_S 可知 n̄_B = 0：负价格把该侧门槛完全消除，卖方在买方规模为零时也愿意入驻。负价格的含义是平台倒贴：平台不仅不从卖家收钱，反而付钱请卖家入驻，买家的门槛因此被降到零，启动不再需要任何初始买家。

### 6. 三条破解路径与淘宝案例

上述条件把平台启动问题转化成一项明确的任务：或者把两侧规模同时推过门槛，或者把门槛本身降到零。现实中的破解方式对应三条路径。其一，补贴一侧：平台对一侧定价为负，发补贴、免佣金，令该侧门槛归零，以人工制造的初始规模撬动另一侧进入，外卖平台补贴用户、支付平台补贴商户都属此类。其二，平台自营一侧：平台自己充当一侧用户，以自营商品或自有内容直接供给初始规模，京东以自营起家、视频平台以自制内容开局都循此路。其三，渐进式接入：先以单边工具积累一侧用户，再开放另一侧，微信先做通讯工具、再开放公众号与小程序即为典型。三种策略的共同逻辑是人为创造初始规模的种子，付出的代价各不相同：补贴付出的是现金，自营付出的是资产与库存周转，渐进式接入付出的是时间。

淘宝对 eBay 易趣的竞争是这个机制的现实演示：2003 年淘宝上线时对卖家侧完全免费，卖家侧门槛被压到零，配套的阿里旺旺又抬高了两侧的价值曲线，易趣的收费模式无法跟进，2006 年易趣中国业务实质退出市场。这一案例的含义：平台竞争的决定性变量是价格结构，总收费水平的差异远小于结构的差异，而结构差异足以决定平台生死。

## 经济学解释（约 1:00）

因果链条：交叉网络外部性使两侧互为价值来源，每一侧都把另一侧的规模当作自己决策的前提，于是"对方不来"成了"我不来"的充分理由，零规模在预期上自我印证。破解的本质是打破这个互相印证：补贴一侧把对方的门槛降到零，自营一侧直接供给初始规模，渐进式接入把一侧先做起来，三条路径的共同点都是先制造一侧规模的事实，再让另一侧的预期跟上来。鸡生蛋问题因此给平台的早期投入提供了清晰的经济学解释：补贴买的是打破零均衡的第一颗种子，用户规模只是种子发芽的结果。

## 算例（约 0:40）

设两侧价值函数为 v_S(n_B) = 0.6n_B、v_B(n_S) = 0.4n_S，平台收费 p_S = 0.3、p_B = 0.2。先求门槛：解 0.6n_B = 0.3，得 n̄_B = 0.5；解 0.4n_S = 0.2，得 n̄_S = 0.5。两侧的门槛都是 0.5，正规模均衡要求买家比例与卖家比例同时不低于 0.5。

初始状态买家 0.3、卖家 0.6：买家规模 0.3 低于门槛 0.5，商家价值 0.6×0.3 = 0.18 低于价格 0.3，商家退出，买家随之收缩，系统退回零均衡。初始状态买家 0.6、卖家 0.6：两侧都越过门槛，商家价值 0.6×0.6 = 0.36 高于 0.3，买家价值 0.4×0.6 = 0.24 高于 0.2，两侧留场，正反馈启动。初始状态买家 0.5、卖家 0.5：两侧价值恰好等于价格，参与与否无差异，这是门槛上的刀刃情形，任何微小扰动都会把系统推向零或推向正规模。再看负价格的效果：平台对卖家改收 p_S = −0.1，此时 v_S(0) = 0 ≥ −0.1，卖家在买家规模为零时也愿意入驻，门槛 n̄_B 归零，启动不再需要任何初始买家。

## 收尾（约 0:20）

本讲小结：交叉网络外部性使两侧互为价值来源；零规模在预期自我实现下是一个真均衡；正规模均衡要求两侧同时越过各自的门槛，任一侧跌破即退回零；负价格把该侧门槛完全消除，补贴一侧、自营一侧、渐进式接入是三条破解路径。下一讲进入 Rochet–Tirole 模型：门槛条件说明了为什么补贴，完整的定价模型回答补贴给哪一侧、补到什么程度。
