# 第三讲 Katz–Shapiro 预期协调模型

> 原型：数学推导节｜对应书节：3.2.2｜目标时长 10 分钟

## 开场定题（约 0:40）

这一讲讲 Katz–Shapiro 预期协调模型，回答一个问题：同一价格对应多个均衡时，哪一个会被选中。网络产品的需求取决于消费者对网络规模的预期，预期自我实现时，同一价格可以对应两个用户规模，模型本身说不出市场会落在哪一个。本讲给出的答案是预期：乐观预期自我实现为大网络均衡，悲观预期自我实现为零规模均衡，预期由此成为厂商可以直接作用的战略变量，补贴、预发布、兼容策略的合理性都建立在这个模型上。

## 主体（约 7:20）

### 1. 预期满足均衡

网络外部性下，消费者的接入决策依赖预期：需求函数为 n = 1 − p/nᵉ，预期规模 nᵉ 越大，接入的人越多。Katz 与 Shapiro 的贡献是把预期直接作为均衡的组成部分，提出预期满足均衡（fulfilled-expectations equilibrium）的概念：预期与实际互相印证，nᵉ = n 与 n = 1 − p/nᵉ 同时成立。两个条件合并，预期满足均衡满足

【屏显】n = 1 − p/n

这个方程在数学上叫不动点方程：把 n 代入需求函数，得到的还是 n。把均衡写成不动点形式是自然的：均衡的定义就是预期与实际互相印证，数学上正是"代入后不变"。这里用到的工具是不动点的求法：不动点方程的根就是全部理性预期均衡，求根只需代数整理，把方程化成 n² − n + p = 0 后套求根公式。方程的两个根已经求出，这里重述结果：

【屏显】n₁* = (1 − √(1−4p))/2 < 1/2

【屏显】n₂* = (1 + √(1−4p))/2 > 1/2

n 一星是临界规模，n 二星是稳定均衡。二者都是预期满足均衡：预期落在这两个规模上，实际需求恰好印证预期。预期满足均衡的求法给了一个通用模板：任何包含预期的模型，都可以用"预期等于实际"这个条件把均衡钉住，这个模板在后面的双边市场与竞争模型里反复使用。

### 2. 预期如何选择均衡

既然两个均衡都是理性的，选择机制就看预期如何调整。设消费者带着预期 nᵉ 进入市场，实际需求为 n = 1 − p/nᵉ，两者的差决定预期的修正方向：实际需求高于预期，预期上调；实际需求低于预期，预期下调。迭代式是这种修正过程的数学写法：每一期的预期等于上一期的实际需求。

【屏显】n(t+1) = 1 − p/n(t)

三个区间依次分析。预期低于 n 一星时，实际需求低于预期，预期向下修正，需求进一步收缩，网络消亡。预期位于 n 一星与 n 二星之间时，实际需求高于预期，预期向上修正，需求扩张，直至 n 二星。预期高于 n 二星时，预期过度乐观，实际需求低于预期，回落至 n 二星。三个区间共同说明，临界规模是预期轨道的分水岭：预期一旦落入某个区间，修正方向就不再回头，一路走向区间的终点。结论一句话：乐观预期自我实现为大网络均衡，悲观预期自我实现为零规模均衡。价格相同的同一产品，可以因预期差异而得到完全不同的市场结果，这是本讲的核心命题。注意悲观预期同样是理性的：预期低导致接入少，接入少印证预期低，悲观者没有被现实打脸，只是被现实证实。多重均衡下，理性预期条件只能圈定可能的均衡集合，不能挑出唯一结果，最终的均衡选择落在预期上，这正是 Katz 与 Shapiro 模型的意义。

### 3. 预期管理：厂商的战略变量

预期决定均衡，而预期可以被影响，预期管理因此成为网络产品竞争的战略变量。厂商有强烈动机操纵预期，手段有三类。其一，预发布（announcement）：提前宣布产品、开放预约，用未来的网络规模承诺撬动当期的接入决策，让消费者相信网络终将成形。其二，补贴首期用户：直接付费购买初始用户，把消费者预期推过临界规模，正反馈随后接管。其三，兼容策略（compatibility）：兼容既有大网络，把对方的存量用户变成自己的初始网络，无需花钱买用户，直接借用对方已经建成的网络修正消费者的预期。三类手段本质相同：都是预期管理。平台"烧钱换增长"的合理性正在于此：补贴的目的在于把消费者预期推过临界规模，当期利润的让渡是为启动正反馈付出的代价。这一代价要按投资来理解：当期让渡的每一分利润，换的是大网络均衡下的长期利润流，预期的价格由此可知。传统产品的营销造势改变的是偏好，网络产品的营销造势改变的是预期，后者可以直接改变均衡的选择，市场结果因此掺入营销的成分，这是网络市场竞争与传统市场竞争的一个重要差别。

预期与现实的这种互相印证，在社会学里早有命名，即自我实现预言（self-fulfilling prophecy）：对情形的定义本身成为情形的一部分。网络外部性把它从社会学现象变成了可以求解的经济模型：预期进入需求函数，预期因此成为均衡方程的一部分，可以被观察、测算与操纵。

### 4. 冷启动问题与跨越策略

网络规模为零时产品对任何人都没有价值，无人愿意成为第一个用户，"先有鸡还是先有蛋"的困局由此而来，这就是冷启动问题（cold start problem）。跨越临界规模的常见策略均围绕预期与初始用户展开。补贴与免费获客最直接：微信支付借 2015 年央视春晚的"摇一摇"红包活动在数日内完成了大规模的用户支付绑定，滴滴与快的的补贴大战同样是付费购买初始网络。预装与渠道合作可以一次性获得用户基数：手机预装、系统捆绑把用户规模直接带到门槛附近。预发布造势用未来预期撬动当期接入：提前宣布产品、开放预约，让消费者相信网络终将成形。兼容既有大网络则把对方的存量用户变成自己的初始网络。策略清单可以很长，但每一条都落在同一个机制上：把预期推过临界规模，正反馈随后接管。这些策略的共同风险：预期一旦撑不过临界规模，投入全部沉没；越过之后正反馈接手，投入即完成使命。

## 经济学解释（约 1:00）

因果链条是：预期塑造接入决策，接入决策塑造实际规模，实际规模反过来验证或否定预期。预期低于临界规模时，现实不断证实悲观，网络螺旋收缩；预期高于临界规模时，现实不断证实乐观，网络螺旋扩张。市场结果因此不完全由基本面决定：同样的产品、同样的价格、同样的消费者，仅仅因为预期不同，一个市场繁荣、另一个市场消亡。这一结论把"信心"从心理词汇变成经济变量：预期是均衡的组成部分，管理预期就是管理市场。平台愿意用真金白银换增长，深层原因就在这里：买的是预期，预期越过临界规模后由正反馈接力。

## 算例（约 0:40）

取价格 p = 0.21，代入求根公式：√(1−4×0.21) = √0.16 = 0.4，两个均衡为 n 一星 = (1−0.4)/2 = 0.3，n 二星 = (1+0.4)/2 = 0.7。同样的价格、同样的产品，市场可能停在 0.7，也可能消亡，差别只在预期。

三组初始预期演示三种命运。预期 0.2，低于临界规模：实际需求 1 − 0.21/0.2 = −0.05，负需求意味着无人接入，网络消亡。预期 0.5，位于两个均衡之间：实际需求 1 − 0.21/0.5 = 0.58，预期上修；再代入 1 − 0.21/0.58 ≈ 0.64，再代入约 0.67，逐步逼近稳定均衡 0.7。预期 0.8，过度乐观：实际需求 1 − 0.21/0.8 ≈ 0.74，回落到 0.7 附近。厂商的工作就是把预期从 0.2 一侧挪到 0.5 以上：同样的价格 0.21，预期 0.2 与 0.5 之差就是市场生死之差，补贴与预发布投入的价值就在这里。

## 收尾（约 0:20）

本讲小结：预期满足均衡把预期作为均衡的组成部分；同一价格对应多个理性预期均衡，乐观预期自我实现为大网络均衡，悲观预期自我实现为零规模均衡；预发布、补贴首期用户、兼容策略都是把预期推过临界规模的手段，平台烧钱换增长的合理性由此而来。下一讲进入鸡生蛋问题：把网络外部性推广到买卖两侧，看双边市场的零均衡如何自我实现、临界规模门槛如何推导。
