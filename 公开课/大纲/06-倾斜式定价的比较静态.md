# 第六讲 倾斜式定价的比较静态

> 原型：数学推导节｜对应书节：4.2.3｜目标时长 10 分钟

## 开场定题（约 0:40）

这一讲讲倾斜式定价：平台对一侧收费极低甚至为负、对另一侧收费较高的定价结构，并回答它的核心问题：谁多付钱、谁获补贴，由什么决定。第 5 讲的 Rochet–Tirole 模型推出了价格结构的公式，本讲对它做比较静态：改变两侧的外部性贡献与需求弹性，价格结构如何随之移动。结论一句话：给另一侧带来收益多的一侧获得补贴，弹性大的一侧在基准模型中反而承担更大份额，两者的对照是最常混淆的点。

## 主体（约 7:20）

### 1. 倾斜式定价的定义

倾斜式定价（skewed pricing）指平台对一侧用户收费极低甚至为负（补贴）、对另一侧收费较高的定价结构：价格结构向弹性大、外部性贡献大的一侧大幅倾斜。经验形态随处可见：外卖平台补贴消费者、向商家抽佣；游戏主机低价甚至亏损出售主机、向游戏销售抽成；支付平台对商户免费、向消费者收费或反之。倾斜式定价在双边市场中最容易观察，又极易与掠夺性定价混淆，因此是辨析题的常客。它的极端形态也印证了价格结构非中性的判定：同样的总收费水平，不同的结构分配带来截然不同的交易规模。单边市场不存在倾斜问题：厂商只有一个价格变量，价格结构是双边市场独有的决策维度。倾斜式定价还解释了平台竞争的胜负手：两个平台的总收费水平相同，结构不同，交易量与利润可以截然不同。

### 2. 因素一：该侧对另一侧的外部性贡献

补贴哪一侧的第一个决定因素，是该侧参与给另一侧带来的收益。这一机制在第 5 讲的便利收益变体里有明确的数理形式：买方参与给卖方带来便利收益 b，b 进入净成本 c−b，买方侧价格为

【屏显】p_B = [η_B/(η_B−1)]·(c − b − p_S)

对 b 做比较静态：b 越大，净成本越低，买方价格越低。判定条件 p_S > c−b 时 p_B < 0：卖方侧承担的费用一旦超过净成本，买方侧价格转负，买方获得净补贴。方向一句话：给另一侧带来收益多的一侧获得补贴，它的参与撬动另一侧规模的杠杆作用最强。便利收益的直觉：b 是卖方从买方存在中白得的好处，它抵消平台的边际成本，公式里 c 一律换成 c−b；b 越大，卖方越愿意承担费用，买方侧获得补贴的空间越大。

### 3. 因素二：该侧的需求弹性

第二个决定因素是需求弹性，这里有一个重要的方向对照。经验上被补贴的一侧通常也是弹性大的一侧：弹性大意味着降价撬动的参与多，补贴的杠杆效果强。但第 5 讲基准模型的封闭解

【屏显】p_i = [η_i/(η_B+η_S−1)]·c

给出相反的方向：两侧需求互不进入对方效用时，弹性大的一侧承担总价格中更大的份额。对照点在于：基准模型里交易量只取决于两侧参与率的乘积，弹性大的那一侧没有外部性杠杆可撬；交叉外部性显式进入效用后，补贴弹性大的一侧才有利可图。经验规律与基准结论方向相反，根源就在外部性是否进入需求。通行口径是：弹性大、外部性贡献大的一侧获得补贴，判断具体平台时两条分别核对。外部性进入效用后链条反转的机制：补贴弹性大的一侧，降价撬动的参与多，该侧参与又撬动另一侧，杠杆效果成倍放大；基准模型里这个放大环节不存在，弹性大的一侧只剩承担份额一条路。

### 4. 辨析：倾斜式定价与掠夺性定价

倾斜式定价的低价侧与掠夺性定价（predatory pricing）表面相似，性质不同。倾斜式定价是双边市场结构的均衡结果：低价侧与另一侧的高价同时存在、相互配套，长期持续；掠夺性定价是单边市场的策略性行为：为排挤对手而低于成本销售，待对手退出后提价回收。判定要点两条：其一，低价是否与另一侧收费构成交叉补贴结构；其二，低价是持续性均衡行为还是阶段性排挤。二者可以并存，补贴战同时具有排挤动机，双边市场下掠夺性定价的判定是反垄断分析的难题，误判为掠夺性定价会导致对正常平台定价的错误干预。两条判定要点中，第一条最关键：倾斜式定价的低价侧是长期结构的一部分，与另一侧的高价相互配套；掠夺性定价的低价是阶段性武器，排挤完成后价格回升。

### 5. 案例：滴滴与快的的补贴大战

2014 年，滴滴与快的在网约车市场展开的补贴战是中国互联网史上规模最大的倾斜式定价竞赛。两家平台同时对乘客与司机双向补贴：乘客每单立减、司机接单奖励。用本讲框架解读：司机侧与乘客侧的交叉外部性极强，车多乘客就愿意等，乘客多司机就有单接；两侧的需求弹性都高，用户多归属、转换成本低。按补贴规则，两侧都应当获得补贴，平台利润只能来自未来赢家通吃后的佣金回收。双方在数月内投入的补贴规模以十亿元计，终局是 2015 年 2 月两家宣布合并，市场从双寡头补贴竞争转入垄断定价阶段：补贴逐步退坡、抽成逐步上调。补贴、合并、提价的三部曲此后在中国平台经济反复出现，共享单车与社区团购皆循此路：网络外部性市场的前期投入以竞争性补贴的形式支出，垄断格局形成后再以佣金的形式回收。补贴大战还有一个细节值得注意：双向补贴下平台两侧都在亏损运营，亏损总额随规模扩大而扩大，规模增长本身成了烧钱的加速器，这也是补贴战难以长期持续的原因。

## 经济学解释（约 1:00）

因果链条分两条。外部性贡献的链条：一侧的参与提升另一侧的价值，平台补贴该侧撬动另一侧入场，另一侧的高价再回收投入，免费侧的亏损构成撬动付费侧的投入成本。需求弹性的链条：给定总价格水平，把一元价格从一侧挪到另一侧，两侧参与率的百分比变动相等时再分摊已无利可图，弹性大的一侧在基准模型中被收取更高价格；外部性进入效用后链条反转，弹性大的一侧成为补贴对象。两条链条的共同结论：倾斜式定价是利润最大化定价的自然结果，与平台是否慷慨无关。把倾斜式定价误读为慷慨或掠夺，都偏离了它的性质：它是结构条件的直接推论，低价侧与高价侧互为存在的理由。

## 算例（约 0:40）

用第 5 讲的封闭解做两组比较静态，边际成本取 c = 1。基准：η_B = 3、η_S = 6，总水平 M = 9/8 = 1.125，p_B = (3/9)×1.125 = 0.375，p_S = (6/9)×1.125 = 0.75，弹性大的卖家侧承担更大份额。验算结构条件：0.375/3 = 0.125，0.75/6 = 0.125，两侧价格弹性比相等。第一组，卖家的弹性从 6 升到 8：总水平 M = 11/10 = 1.1，p_B = (3/11)×1.1 = 0.3，p_S = (8/11)×1.1 = 0.8，结构条件依然成立：0.3/3 = 0.1，0.8/8 = 0.1。弹性升高后，卖家价格从 0.75 升到 0.8，买家价格从 0.375 降到 0.3，总加价空间从 1.125 收窄到 1.1：弹性越强，总水平越低，但弹性大的一侧承担得更多。第二组，买方给卖方带来便利收益 b = 0.9：p_B = [3/(3−1)]×(1−0.9−0.75) = 1.5×(−0.65) = −0.975，买方价格转负，补贴出现。两组数字恰好演示两个因素：弹性决定分摊份额，外部性贡献决定补贴方向。

## 收尾（约 0:20）

本讲小结：倾斜式定价是价格结构向一侧大幅倾斜的均衡结果；补贴哪一侧由两个因素决定，给另一侧带来收益多的一侧获得补贴，弹性大的一侧在基准模型中承担更大份额、外部性进入效用后获得补贴；与掠夺性定价的差别在结构的持续性。下一讲进入三级价格歧视：厂商对可识别的不同群体收取不同价格，各群体按自己的弹性独立定价，弹性小的群体被收取更高价格，其方向与本讲基准模型的弹性分摊规则恰好相反，两讲的对照值得留意。
